# Opciones para hacer la terminal más grande en GitHub

---

### Opción 1: Diseño ASCII Ampliado (En Bloque de Código)

```text
+-----------------------------------------------------------------------+
|  🔴 🟡 🟢  mariano@utn: ~                                              |
+-----------------------------------------------------------------------+
|                                                                       |
|  $ whoami                                                             |
|    Mariano Chirino - Estudiante (UTN)                                 |
|                                                                       |
|  $ cat ubicacion.txt                                                  |
|    Mendoza, Argentina                                                 |
|                                                                       |
|  $ cat stack.txt                                                      |
|    MySQL | PostgreSQL | Python | JavaScript | Java                    |
|                                                                       |
|  $ ./ahora.sh                                                         |
|    Respaldo y recuperación de bases de datos                          |
|                                                                       |
|  $ echo $IA                                                           |
|    OpenCode + Spec-Driven Development                                 |
|                                                                       |
|  $ _                                                                  |
|                                                                       |
+-----------------------------------------------------------------------+
```
